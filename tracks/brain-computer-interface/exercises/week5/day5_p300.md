## 核心概念

### 1. P300 特点

事件相关電位 P300：
- 出现在刺激后 300ms 左右
- 与注意和决策相关
- 出现在头顶 Cz 区域
- 用于字符选择（如 P300 Speller）

### 2. P300 分类

```python
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.svm import SVC

def classify_p300(X_train, y_train, X_test):
    """P300 分类"""
    clf = LinearDiscriminantAnalysis()
    clf.fit(X_train, y_train)
    return clf.predict(X_test)
```

### 3. 信号增强

```python
# 多次平均增强 SNR
def average_p300(epochs, n_averages=50):
    """平均多个 epoch"""
    target_epochs = epochs['Target'][:n_averages]
    return target_epochs.average()
```

### 4. 特征

# 时域特征
features = {

### 5. P300 Speller 原理

```python
# 行列刺激范式
# 字符排列成 6x6 矩阵
# 随机闪烁行/列
# 用户注视目标字符
# 当目标字符所在行/列闪烁时产生 P300
```
