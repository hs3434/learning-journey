## 1. 什么是频谱泄漏

当你对一段有限长信号做 FFT 时，如果信号在窗口两端**不连续**（没有恰好完成整数个周期），信号的能量就会从真实频率"泄漏"到邻近的频率 bin 中。

**回声室类比**：在回声室里播放音乐：
- 音乐在结尾处**自然收尾**（整数周期）→ 声音干净利落
- 音乐在**高音处被突然切断**（非整数周期）→ 回声室里混入各种杂音

这个"被切断"产生的杂音，就是**频谱泄漏**。

## 2. 数学原理

### 2.1 核心等式

$$
x_T(t) = x(t) \cdot w(t) \quad \text{（时域：信号乘矩形窗 = 截断）}
$$

$$
X_T(f) = X(f) * W(f) \quad \text{（频域：频谱卷积窗的频谱 = 泄漏）}
$$

其中 $*$ 表示卷积，$\cdot$ 表示相乘。

这是傅里叶变换的**乘法-卷积对偶性**：时域相乘 → 频域卷积。

### 2.2 矩形窗的频谱

矩形窗 $w(t)$（1 在 $[0,T]$，0 在其他）的频谱是 sinc 函数：

$$
W(f) = T \cdot \operatorname{sinc}(fT) = T \cdot \frac{\sin(\pi f T)}{\pi f T}
$$

sinc 函数的特征：
- **主瓣**：在 $f=0$ 处，峰值 $= T$
- **旁瓣**：在主瓣两侧，逐渐衰减
- **零点**：在 $f = k/T$（$k = \pm 1, \pm 2, \ldots$）

### 2.3 单频信号的截断频谱

对于 $x(t) = \sin(2\pi f_0 t)$，其理想频谱是 $\delta(f - f_0)$（delta 脉冲）。

截断后的频谱：

$$
X_T(f) = \delta(f - f_0) * T\operatorname{sinc}(fT) = T\operatorname{sinc}\big((f - f_0)T\big) \quad \text{（delta 卷积 = 平移）}
$$

即 sinc 函数平移到 $f_0$ 处。

### 2.4 FFT 采样点

FFT 在离散频率点上采样：

$$
f_k = \frac{k \cdot f_s}{N} = \frac{k}{T} \quad (k = 0, 1, 2, \ldots)
$$

关键发现：**FFT bin 的位置恰好等于 sinc 函数零点的位置！**

### 2.5 整数周期：零点对齐 → 无泄漏

当 $f_0 = m/T$（整数个周期，$m$ 为整数）时：

$$
X_T(f_k) = T\operatorname{sinc}\big((f_k - f_0)T\big) = T\operatorname{sinc}(k - m)
$$

当 $k \neq m$ 时，$k-m$ 是非零整数，$\operatorname{sinc}(k-m) = \frac{\sin(\pi n)}{\pi n} = 0$

**结论**：只有第 $m$ 个 bin 非零，其他所有 bin = 0。**无泄漏！**

### 2.6 非整数周期：零点错位 → 泄漏

当 $f_0 \neq m/T$ 时：

$$
f_k - f_0 \neq \text{整数}/T
$$

sinc 在 $f_k$ 处的值 $\neq 0$，所有 bin 都有非零值。**泄漏！**

### 2.7 周期延拓视角（等价理解）

FFT 假设信号是**周期延拓**的：
- **整数周期**：延拓后首尾无缝衔接，无跳变 → 无额外频率成分
- **非整数周期**：延拓后在边界处有**跳变** → 跳变包含所有高频成分 → 泄漏

**两种视角的统一**：
- 跳变越剧烈 → 矩形窗越"硬" → sinc 旁瓣越高 → 泄漏越严重
- 渐变越平滑 → 窗越"软" → sinc 旁瓣越低 → 泄漏越少

## 3. 窗函数：抑制泄漏的武器

### 3.1 核心矛盾

| 指标 | 含义 | 矩形窗 | 汉宁窗 |
|------|------|--------|--------|
| 主瓣宽度 | 频率分辨率 | 最窄 | 2 倍宽 |
| 第一旁瓣 | 泄漏程度 | -13.3 dB | -31.5 dB |

**主瓣越窄 = 频率分辨率越高，但旁瓣越高 = 泄漏越严重。两者矛盾！**

### 3.2 常用窗函数对比

| 窗函数 | 第一旁瓣 | 主瓣宽度 | 特点 |
|--------|----------|----------|------|
| 矩形窗 | -13.3 dB | 最窄 | 频率分辨率最高，泄漏最严重 |
| 汉宁窗 | -31.5 dB | 2倍宽 | BCI 默认选择，平衡 |
| 海明窗 | -42.7 dB | 2倍宽 | 旁瓣更不均匀但最低旁瓣更低 |
| 布莱克曼窗 | -58.1 dB | 3倍宽 | 泄漏最少，分辨率最低 |

### 3.3 类比理解

窗函数就像给信号加"淡入淡出"效果：
- **矩形窗** = 硬切 → 突兀的边缘 → 泄漏严重
- **汉宁窗** = 渐入渐出 → 平滑边缘 → 泄漏减少
- **代价**：主瓣变宽 → 频率分辨率下降

### 3.4 Python 代码

```python
import numpy as np

# 矩形窗（无窗 = 默认）
X_rect = np.fft.rfft(signal)

# 汉宁窗（BCI 默认）
X_hann = np.fft.rfft(signal * np.hanning(N))

# 布莱克曼窗（需要最少泄漏时）
X_black = np.fft.rfft(signal * np.blackman(N))
```

## 4. BCI 中的实战影响

### 4.1 为什么频谱泄漏在 BCI 中特别重要

1. **Alpha 波 (8-12Hz) vs Mu 波 (8-13Hz)**
   - 泄漏严重时，两个频谱峰会"糊在一起"，无法区分

2. **SSVEP 检测**
   - SSVEP 频率非常精确（如 12Hz），泄漏会让邻近频率也出现峰值 → 误判

3. **事件相关去同步 (ERD)**
   - 需要精确测量特定频段的能量变化，泄漏会模糊边界

4. **STFT 时频分析**
   - 窗口越短 → 频率分辨率越低 → 泄漏越严重
   - 这是 STFT 时间-频率分辨率的根本矛盾

### 4.2 实战建议

- 默认用汉宁窗 (`scipy.signal.windows.hann`)
- 需要精确频率 → 用较长窗口 + 矩形窗
- 需要抑制泄漏 → 用较短窗口 + 汉宁/布莱克曼窗
- BCI 最常用：汉宁窗（平衡选择）
- 代码：`np.fft.rfft(signal * np.hanning(N))`

## 5. 与 Gibbs 现象的联系

方波在傅里叶级数展开时，跳变处总会有约 9% 的过冲（Gibbs 现象），无论加多少项都无法消除。

频谱泄漏和 Gibbs 现象本质上是**同一个问题**：
- Gibbs 现象 = 频域截断（有限谐波）→ 时域跳变处过冲
- 频谱泄漏 = 时域截断（有限窗口）→ 频域旁瓣泄漏

截断 = 信息丢失，无论在哪个域截断，都会在另一个域产生"振铃"效应。
