## 1. STFT 的局限：固定窗长

STFT 用**固定长度**的窗做分帧 FFT，意味着所有频率共享同一时间-频率分辨率。

**问题**：EEG 不同频段对分辨率的需求不同：
- **低频（delta 1Hz, theta 4Hz）**：变化慢，需要长窗看清楚频率
- **高频（beta 20Hz, gamma 40Hz）**：变化快，需要短窗捕捉时间

STFT 选了 nperseg=128，对所有频率一视同仁 → **低频时间太粗糙，高频频率太模糊**。

**类比**：STFT 就像穿同一双鞋爬山和跑步 → 两种场景都不够好。小波变换 = 自适应换鞋：爬缓坡穿登山靴（长窗），跑陡坡穿跑鞋（短窗）。

## 2. 连续小波变换（CWT）

### 2.1 核心思想

小波变换不用固定的正弦波基函数，而是用**可伸缩的小波**（wavelet = 小波 = 有限长的波动）：

$$
W(a, b) = \frac{1}{\sqrt{a}} \int_{-\infty}^{+\infty} x(t) \cdot \psi^*\left(\frac{t-b}{a}\right) dt
$$

其中：
- $\psi(t)$ = 母小波（mother wavelet）
- $a$ = 尺度参数（stretch → 频率越低，压缩 → 频率越高）
- $b$ = 平移参数（时间位置）

### 2.2 尺度 vs 频率

尺度 $a$ 和频率 $f$ 成反比：

$$
f = \frac{f_c}{a \cdot \Delta t}
$$

其中 $f_c$ 是母小波的中心频率，$\Delta t$ 是采样间隔。

| 尺度 $a$ | 含义 | 效果 |
|----------|------|------|
| 大 | 小波被拉伸 | 看低频，长窗，频率分辨率高 |
| 小 | 小波被压缩 | 看高频，短窗，时间分辨率高 |

### 2.3 与 STFT 的对比

| 特性 | STFT | CWT |
|------|------|-----|
| 窗长 | 固定 | 随频率自适应 |
| 基函数 | 正弦/余弦（无限长） | 小波（有限长） |
| 频率轴 | 等间距 | 等比间距（对数尺度） |
| 分辨率 | 所有频率一致 | 低频频率分辨率高，高频时间分辨率高 |
| 类比 | 固定焦距镜头 | 变焦镜头（自动对焦） |

## 3. 常用母小波

### 3.1 Morlet 小波（BCI 最常用）

$$
\psi(t) = \pi^{-1/4} e^{j\omega_0 t} e^{-t^2/2}
$$

= 正弦波 × 高斯包络 = "带高斯帽的频率"

**特点**：
- 频域定义明确，适合频率分析
- BCI/EEG 研究的默认选择
- `scipy.signal.cwt` 和 MNE-Python 都支持

### 3.2 其他常用小波

| 小波 | 特点 | 适用场景 |
|------|------|---------|
| **Morlet** | 频域最优，连续 | EEG 时频分析（默认） |
| **Daubechies (db4, db8)** | 正交，紧支撑 | 信号去噪、压缩 |
| **Haar** | 最简单，方波 | 边缘检测、教学 |
| **Mexican Hat** | 二阶高斯导数 | 峰值检测 |

### 3.3 类比理解

选择母小波 = 选择"观察信号的镜头"：
- **Morlet** = 频率显微镜（看频率成分）
- **Haar** = 边缘检测器（看突变）
- **Daubechies** = 多功能刀（去噪+压缩）

## 4. 小波去噪

### 4.1 原理

1. 对信号做离散小波变换（DWT），分解成多层细节系数 $d_1, d_2, \ldots$ 和近似系数 $a_n$
2. 噪声集中在高频细节系数中
3. 对细节系数做**阈值处理**（软阈值/硬阈值），压制噪声
4. 重构信号

### 4.2 分解结构

```
原始信号
├── d1 (最高频细节) ← 噪声
├── d2
├── d3
├── d4
└── a4 (低频近似) ← 信号主体
```

### 4.3 阈值选择

| 方法 | 说明 |
|------|------|
| 硬阈值 | 系数 < 阈值 → 置零；≥ 阈值 → 保留 |
| 软阈值 | 系数 < 阈值 → 置零；≥ 阈值 → 减去阈值（更平滑） |

### 4.4 Python 代码

```python
import pywt

# 小波分解
coeffs = pywt.wavedec(eeg, 'db4', level=5)
# coeffs = [a5, d5, d4, d3, d2, d1]

# 软阈值去噪
threshold = np.std(coeffs[-1]) * np.sqrt(2 * np.log(len(eeg)))
denoised_coeffs = [pywt.threshold(c, threshold, mode='soft') for c in coeffs]

# 重构
eeg_denoised = pywt.waverec(denoised_coeffs, 'db4')
```

## 5. ICA：独立成分分析

### 5.1 问题：EEG 中的伪迹

| 伪迹类型 | 来源 | 特征 |
|----------|------|------|
| 眼眨 | 眼轮匝肌 | 大幅低频偏转，额叶最大 |
| 眼动 | 眼球移动 | 缓慢基线漂移，额叶 |
| 心电 (ECG) | 心脏跳动 | 周期性尖峰，约 1Hz |
| 肌电 (EMG) | 面部/颈部肌肉 | 高频噪声，>30Hz |

### 5.2 ICA 核心思想

**鸡尾酒会问题**：房间里多个人同时说话（源信号），多个麦克风同时录音（混合信号）。ICA 从混合录音中分离出每个人的声音。

$$
X = A \cdot S \quad \text{（观测 = 混合矩阵 × 源信号）}
$$

$$
S = W \cdot X \quad \text{（源信号 = 解混矩阵 × 观测）}
$$

- $X$：观测信号（$n$ 个 EEG 通道）
- $S$：源信号（$n$ 个独立成分）
- $A$：混合矩阵（$n \times n$）
- $W = A^{-1}$：解混矩阵

### 5.3 ICA 的假设

1. 源信号**统计独立**
2. 源信号**非高斯分布**（最多一个高斯）
3. 混合矩阵 $A$ 是方阵（成分数 = 通道数）

### 5.4 ICA 如何去除伪迹

1. 对 EEG 数据运行 ICA → 得到 $n$ 个独立成分
2. **识别伪迹成分**：
   - 眼眨成分：额叶权重最大，时域有大偏转
   - 心电成分：周期性尖峰
   - 肌电成分：高频，弥散分布
3. 将伪迹成分置零
4. 重构信号：$X_{\text{clean}} = A \cdot S_{\text{clean}}$

### 5.5 类比理解

**ICA = 拆解一杯鸡尾酒**

EEG 信号就像一杯混合饮料：里面有果汁（脑电）、牛奶（眼电）、糖浆（心电）、冰块（肌电）。

ICA 不能"逆向化学"把混在一起的成分拆开，但它能找到**统计独立的"配方"**，告诉你这杯饮料由哪些"成分"按什么比例混合而成。然后你把不想要的成分（牛奶、糖浆）去掉，重新混合 → 干净的果汁（脑电）。

## 6. MNE-Python 实战 ICA

### 6.1 标准流程

```python
import mne
from mne.preprocessing import ICA

# 1. 加载数据
raw = mne.io.read_raw_fif('eeg_data.fif', preload=True)

# 2. 预处理：滤波（ICA 前 高通 1Hz 去漂移）
raw.filter(l_freq=1.0, h_freq=None)

# 3. 创建 ICA 对象
ica = ICA(n_components=20, random_state=42, method='fastica')

# 4. 拟合 ICA
ica.fit(raw)

# 5. 查看成分（交互式）
ica.plot_components()    # 拓扑图
ica.plot_sources(raw)    # 时域波形

# 6. 排除伪迹成分
ica.exclude = [0, 3]     # 手动选择（0=眼眨, 3=心电）

# 7. 应用 ICA 去除伪迹
raw_clean = ica.apply(raw.copy())
```

### 6.2 自动检测伪迹成分

MNE 提供辅助函数：

```python
from mne.preprocessing import find_ecg_events, find_eog_events

# 自动找心电成分
ecg_idx, ecg_scores = ica.find_bads_ecg(raw, method='correlation')
ica.exclude.extend(ecg_idx)

# 自动找眼电成分
eog_idx, eog_scores = ica.find_bads_eog(raw, method='correlation')
ica.exclude.extend(eog_idx)
```

## 7. 小波 vs ICA：选择指南

| 场景 | 选择 | 原因 |
|------|------|------|
| 去高频噪声 | 小波去噪 | 简单高效，不需要多通道 |
| 去眼眨/心电伪迹 | ICA | 需要空间分离（多通道信息） |
| 时频分析 | CWT（Morlet） | 自适应分辨率 |
| 实时去噪 | 小波 | 计算快，因果可实现 |
| 离线预处理 | ICA | 效果更好，但需要多通道 |

**BCI 标准流程**：

```
原始 EEG → 带通滤波 (0.5-40Hz) → Notch (50Hz) → ICA 去伪迹 → 干净信号
```

## 8. 关键要点总结

1. **STFT 固定窗长 → 小波变换自适应窗长**：低频用长窗（频率清晰），高频用短窗（时间清晰）
2. **Morlet 小波 = EEG 时频分析的默认选择**
3. **小波去噪 = DWT 分解 → 阈值处理 → 重构**
4. **ICA = 鸡尾酒会分离器**：从多通道混合信号中分离独立成分
5. **ICA 去伪迹**：识别眼眨/心电/肌电成分 → 置零 → 重构干净信号
6. **BCI 标准预处理**：带通 → Notch → ICA
