# Week 5 Day 15：深度学习在 BCI 中的应用

## 1. 为什么 BCI 需要深度学习？

传统方法（CSP + LDA、CCA、Stepwise LDA）在受控实验室环境下效果不错，但存在根本局限：

| 问题 | 传统方法 | 深度学习 |
|------|---------|---------|
| 手工特征设计 | 需要领域知识选择特征 | 自动学习特征 |
| 跨被试泛化 | 差（每个被试需重新校准） | 可训练跨被试模型 |
| 非线性模式 | LDA 只能线性分类 | 天然处理非线性 |
| 复杂范式 | 每种范式需定制算法 | 统一框架 |

### 打个比方

- **传统方法** = 手工打造工具：锤子钉钉子，锯子锯木头，每个任务对应一把专用工具
- **深度学习** = 万能工厂：给它原材料（原始 EEG），它自己设计流水线，从原料到成品一条龙

但深度学习不是万能的——BCI 数据量小、个体差异大、可解释性差，这些是实际落地的核心挑战。

## 2. BCI 中的深度学习架构

### 2.1 EEG 数据的"图像化"表示

EEG 数据是三维的：$(n\_channels, n\_times, 1)$，可以类比为一张"灰度图"：

```
通道数 × 时间点 → "高" × "宽"
每个采样值 → "像素灰度"

16 通道 × 500 时间点 = 16×500 的"图像"
```

这就是为什么 CNN 在 BCI 中最流行的原因——空间卷积核学习通道间关系，时间卷积核学习时间模式。

### 2.2 四大主流架构

#### (1) EEGNet — 轻量级标杆（2018）

```
输入: (1, C, T)  — C=通道数, T=时间点
  ↓
深度卷积 (Depthwise Conv): 每个通道独立提取时间特征
  ↓
深度可分离卷积 (Separable Conv): 学习通道间空间模式
  ↓
全连接 → 分类
```

核心设计思想：
- **深度可分离卷积** = 时间特征学习 + 空间特征学习 分离进行
- 参数量极小（~2K 参数），适合 BCI 的小数据场景
- 跨范式通用：P300、MI、SSVEP 都能用的同一架构

类比：
- CSP + LDA = 精密手术刀（专为 MI 设计）
- EEGNet = 瑞士军刀（通用但够用）

#### (2) Shallow ConvNet — 浅层高效（2017）

```
输入: (1, C, T)
  ↓
时间卷积 (大核): 提取 ERP 波形模式
  ↓
空间卷积: 学习通道权重（类似 CSP）
  ↓
平方 + 对数: 模拟 log-var 特征（类似 CSP 流程）
  ↓
全连接 → 分类
```

关键洞察：平方+对数操作等价于 CSP 的 $\log(w^T C w)$，所以 Shallow ConvNet 本质是 **"可学习的 CSP + LDA"**。

#### (3) Deep ConvNet — 深层特征（2017）

```
4 层卷积堆叠:
  Conv1: 时间模式提取
  Conv2: 空间模式提取
  Conv3-4: 高级时频特征
  ↓
全连接 → 分类
```

比 Shallow ConvNet 更强，但更容易过拟合（BCI 数据量通常不够）。

#### (4) TCN（时间卷积网络）— 序列建模

```
因果膨胀卷积 (Causal Dilated Conv):
  感受野指数增长: 1 → 2 → 4 → 8 → 16 → ...
  不递归但能捕捉长程时间依赖
  ↓
全连接 → 分类
```

适合需要长程时间依赖的 BCI 任务（如连续 MI 解码）。

### 2.3 架构对比

| 模型 | 参数量 | 适用场景 | 训练数据需求 | 跨被试泛化 |
|------|--------|---------|-------------|-----------|
| EEGNet | ~2K | 通用 | 低（50+ trials） | 中 |
| Shallow ConvNet | ~5K | MI/ERP | 中（100+ trials） | 中 |
| Deep ConvNet | ~50K | 复杂范式 | 高（500+ trials） | 差 |
| TCN | ~20K | 连续解码 | 中 | 中 |

## 3. EEGNet 详解 — BCI 的"ResNet 时刻"

### 3.1 为什么 EEGNet 这么重要？

类比计算机视觉领域的 ResNet（2015）：
- ResNet 之前：每个新任务需要设计新架构
- ResNet 之后：一个架构覆盖所有视觉任务，成为"默认起点"

EEGNet 对 BCI 的意义类似：
- EEGNet 之前：P300 用 LDA，MI 用 CSP+LDA，SSVEP 用 CCA
- EEGNet 之后：一个架构覆盖所有 BCI 范式，成为"默认起点"

### 3.2 EEGNet 的三步卷积

**第一步：时间卷积**（学习 ERP 波形/振荡模式）

$$h_t^{(1)} = \text{Conv1D}(X, w_t)$$

- 卷积核大小 = 采样率/2（如 250Hz → 核大小 125，覆盖 500ms）
- 每个 filter 在所有通道上共享权重
- 类比：在所有电极上"扫描"特定时间模式

**第二步：深度卷积**（学习每个通道的独立时间模式）

$$h_s^{(2)} = \text{DepthwiseConv}(h_t^{(1)}, w_s)$$

- 每个通道独立卷积，不跨通道混合
- 类比 CSP 中的空间滤波，但这里是"学习出来的"

**第三步：可分离卷积**（学习通道间线性组合）

$$h^{(3)} = \text{PointwiseConv}(h_s^{(2)}, w_p)$$

- 1×1 卷积，线性组合各通道
- 类比 CSP 中的 $w^T X$，但权重是学习出来的

### 3.3 EEGNet vs 传统方法

| 环节 | CSP + LDA | EEGNet |
|------|-----------|--------|
| 空间滤波 | 手工优化（协方差特征分解） | 数据驱动学习（深度卷积） |
| 特征提取 | log-var（手工设计） | 自动（网络端到端） |
| 分类器 | LDA（线性） | Softmax（非线性） |
| 输入 | 预处理后的频段数据 | 原始/轻度预处理数据 |
| 流程 | 多步串联 | 端到端 |

## 4. 训练技巧 — BCI 特有问题

### 4.1 数据量不足

BCI 的核心矛盾：**深度学习需要大数据，BCI 只有小数据**。

| 数据集 | Trials 数 | 深度学习"够用"线 |
|--------|----------|----------------|
| 典型 BCI 校准 | 50-200 | 远不够 |
| BCI Competition | 200-500 | 勉强 |
| ImageNet | 1,280,000 | 标准量级 |

解决方案：

1. **数据增强**（Data Augmentation）
   - 时间平移：在时间轴上随机偏移 ±50ms
   - 通道丢弃：随机将 1-2 个通道置零（模拟坏通道）
   - 高斯噪声：添加 SNR=20dB 的噪声
   - 频段掩码：随机遮蔽某个频段（类似 SpecAugment）

2. **迁移学习**（Transfer Learning）
   - 在大量被试数据上预训练 → 在新被试上微调
   - 可以将校准时间从 20 分钟缩短到 2 分钟
   - 这也是目前 BCI 深度学习最实用的方向

3. **正则化**
   - Dropout（0.5）
   - 权重衰减（L2 正则）
   - 早停（Early Stopping）

### 4.2 跨被试泛化

EEG 信号个体差异极大——不同人的"大脑指纹"不同：

```
被试 A 的 MI 模式: 左手想象 → C4 区域 μ 节律 ERD
被试 B 的 MI 模式: 左手想象 → C3 区域 β 节律 ERD
被试 C 的 MI 模式: 左手想象 → 广泛额叶 θ 增强
```

解决思路：
- **域自适应**（Domain Adaptation）：对齐源域和目标域的特征分布
- **元学习**（Meta-Learning）：学习"如何快速适应新被试"
- **被试无关特征**：训练时加入被试 ID 作为条件

### 4.3 实时性约束

BCI 系统要求低延迟推理：

| 方法 | 推理时间 (单 trial) | 适合实时？ |
|------|-------------------|-----------|
| CSP + LDA | < 1 ms | ✅ |
| EEGNet | ~5 ms | ✅ |
| Transformer | ~50 ms | ⚠️ 边界 |
| 大型 CNN | ~100 ms | ❌ |

EEGNet 的轻量设计（2K 参数）使其推理时间 ~5ms，完全满足实时要求。

## 5. 从传统到深度学习的迁移路线

### 5.1 什么时候用深度学习？

```
                    传统方法够用？
                    ┌─────┐
                    │  是  │ → 继续用传统方法（CSP+LDA、CCA）
                    └──┬──┘
                       │ 否
                    ┌─────┐
                    │ 数据够多？(>200 trials)
                    │ 或者有预训练模型？
                    └──┬──┘
                    ┌───┴───┐
                   是        否
                    ↓         ↓
               EEGNet     传统方法 + 数据增强
               微调           或迁移学习
```

**判断原则**：
- 单被试、少数据 → 传统方法更稳
- 多被试、大数据 → 深度学习更有优势
- 跨被试/跨session → 深度学习 + 迁移学习

### 5.2 实践路线图

```
阶段 1: 传统方法做基线（CSP+LDA, CCA, Stepwise LDA）
  ↓
阶段 2: EEGNet 作为"升级选项"（替换分类器部分）
  ↓
阶段 3: 迁移学习实现跨被试泛化
  ↓
阶段 4: 定制架构（针对特定范式优化）
```

## 6. 前沿趋势

### 6.1 自监督学习

不需要标签，从大量无标注 EEG 中学习通用表征：

```
方法 1: 对比学习 — 同一 trial 的两种增强应该相似
方法 2: 掩码预测 — 遮住一段时间，让模型预测
方法 3: 时序预测 — 给前半段，预测后半段
```

优势：BCI 实验中无标签数据远多于有标签数据（采集容易，标注费时）。

### 6.2 Foundation Models

2023-2024 年出现的 EEG 基础模型：
- **Labram**：在大规模 EEG 数据上预训练的 Transformer
- **EEG-Foundation**：自监督预训练 + 下游任务微调
- **BIOT**：跨被试、跨数据集的通用 EEG 编码器

类比 NLP 领域：BERT/GPT 之前每个任务从头训练，之后只需微调。BCI 可能也在经历同样的转变。

### 6.3 可解释性

深度学习"黑箱"问题在 BCI 中尤其严重——医生和患者需要知道"为什么"：

- **梯度可视化**（Grad-CAM）：看网络关注 EEG 的哪个时间段
- **特征反演**：将学到的特征"翻译"回可理解的 ERP 成分
- **注意力权重**：Transformer 的注意力机制天然提供可解释性
