# 脑机接口软件工程师 — 短板补齐分析

## 背景

生物信息工程师，有 Python 项目经验，目标岗位：**脑机接口软件工程师**。

## 岗位职责

1. 参与脑机接口系统中脑电数据处理工具的设计与开发
2. 基于 Python 构建自动化解码处理 pipeline
3. 基于主流 GUI 框架开发数据处理工具界面，实现流程的可视化与自动化执行
4. 将科研代码（MATLAB/Python）工程化与模块化，提升稳定性与复用性
5. 与算法及实验团队协作，优化数据处理效率与实时性
6. 构建从原始数据到解码的标准化处理工具，实现科研 pipeline 向工程系统转化

## 核心技能要求

1. 熟练掌握 Python，熟悉 NumPy、SciPy、Pandas 等科学计算库（了解 PyTorch 更佳）
2. 具备 Qt 或其他相关 GUI 开发经验
3. 理解基本信号处理方法：滤波、FFT/STFT、小波分析、去伪迹、特征提取等
4. 理解基本解码模型的框架，熟悉其输入输出形式及整体处理流程

## 加分项

1. 有 EEG/LFP/Spike 处理经验，或使用过 MNE-Python、FieldTrip 等工具
2. 有 BCI 解码经验（动作解码、语音解码、SSVEP），使用深度学习或 Transformer 进行解码
3. 有完整项目经验（尤其是可实际使用的 GUI 工具或工程系统）
